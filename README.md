# Cloud SOC Lab: Wazuh SIEM & Detection Engineering

Laboratorio defensivo (Blue Team) desplegado en la nube enfocado en telemetría en tiempo real, ingeniería de detección bajo MITRE ATT&CK y análisis de incidentes.

## Detecciones Implementadas
- Detección de Web Shells con File Integrity Monitoring (FIM / MITRE T1505.003).
- Detección de comandos ofuscados en Base64 (MITRE T1027).
